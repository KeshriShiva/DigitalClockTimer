# Digital Clock & Countdown Timer in Java

A simple **console-based Java application** that displays a **real-time digital clock** and runs a **customizable countdown timer** using Java’s time-related APIs.

---

## 📌 Project Overview

This project demonstrates how to work with **time manipulation, formatting, and threading** in Java.  
Users can view the current system time in real-time or start a countdown timer by providing the duration in seconds.

---

## ✨ Features

- Real-time digital clock (HH:mm:ss format)
- Custom countdown timer
- Menu-driven interface
- Uses Java Time API
- Second-by-second updates using threading

---

## 🛠️ Technologies Used

- Java (Core Java)
- Java Time API (`LocalTime`, `DateTimeFormatter`)
- JDK 8 or higher
- Command Line / Terminal
